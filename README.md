# Моя книжная полка

Учебный проект на Django: список книг из базы данных и добавление новых книг через форму.

## Что умеет сайт

- главная страница со всеми книгами из базы данных;
- карточка книги: название, автор, краткое описание и статус;
- визуальное различие прочитанных и непрочитанных книг;
- страница добавления книги с валидацией формы и сообщением об успехе;
- перенаправление на главную страницу после сохранения;
- общее количество книг, число прочитанных и книг «в планах»;
- отдельный CSS-файл в папке `static`;
- модель `Book`, зарегистрированная в админской панели.

## Стек

- Python 3.14
- Django 6.1.3
- SQLite

## Запуск

1. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   ```

   Windows:

   ```bash
   venv\Scripts\activate
   ```

   macOS/Linux:

   ```bash
   source venv/bin/activate
   ```

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Примените миграции:

   ```bash
   python manage.py migrate
   ```

4. Запустите сервер:

   ```bash
   python manage.py runserver
   ```

5. Откройте сайт:

   - главная страница: http://127.0.0.1:8000/
   - добавление книги: http://127.0.0.1:8000/add/
   - админка: http://127.0.0.1:8000/admin/

## Админская панель

В архиве уже есть база данных с демонстрационными книгами и суперпользователем:

- логин: `admin`
- пароль: `LibraryAdmin2026!`

Пароль демонстрационный — перед публикацией проекта смените его или создайте нового суперпользователя:

```bash
python manage.py createsuperuser
```

## Модель Book

| Поле | Тип | Назначение |
| --- | --- | --- |
| `title` | `CharField` | название книги |
| `author` | `CharField` | автор книги |
| `description` | `TextField` | краткое описание |
| `is_read` | `BooleanField` | прочитана ли книга, по умолчанию `False` |

Метод `__str__` возвращает название книги.
